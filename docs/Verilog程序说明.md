# Verilog程序说明

## 端口

| 端口 | 方向 | 说明 |
|---|---|---|
| `clk_2m` | 输入 | 2 MHz时钟 |
| `rst_n` | 输入 | 低有效复位 |
| `sensor_in[2:0]` | 输入 | 三路传感器0/1状态 |
| `audio_out` | 输出 | 送往LM386的3.3 V方波 |
| `sensor_led[2:0]` | 输出 | 显示消抖后的三路状态 |
| `note_code[2:0]` | 输出 | 当前音阶编码 |

## 逻辑结构

1. 三路输入各经两级同步器，降低亚稳态风险。
2. 每路连续稳定10 ms后才更新，实现数字消抖。
3. 三路稳定状态直接作为3位音阶编码。
4. 根据编码选择分频计数值，计数到达半周期时翻转方波。
5. 编码变化时重新计数，`000`时立即静音。
