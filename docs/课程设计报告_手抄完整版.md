# 手指钢琴

> 使用说明：本稿按16K小页纸手抄，正文约17～20页；封面、目录、附录图纸和实物照片另计。封面信息、页码和最终电阻数量由本人填写。图名写在图下方，表名写在表上方。

## 摘要

本课程设计完成了一种基于柔性薄膜压力传感器、模拟信号调理电路、FPGA数字控制和LM386音频功放的手指钢琴。系统选用三只柔性薄膜压力传感器作为输入元件，传感器受压时阻值减小，经过采样、跟随、参考和差分比较等模拟处理后，形成可被FPGA稳定识别的低电平；松开传感器时输出高电平。三路信号分别输入XC3S50AN FPGA的P76、P77和P78脚，FPGA依据三位二进制编码选择音符，并以2 MHz时钟为基准完成分频，产生C4至B4七个音符的方波。音频信号从P90脚输出，经100 nF耦合电容、100 kΩ电位器和LM386功放驱动扬声器。实际调试结果显示，三路FPGA输入在按下和不按状态下均有清晰的低/高电平差异；七个音符的实测频率与标准频率误差均小于0.02%；扬声器可随编码改变音高，在111状态下保持静音。设计完成了手指压力采集、数字编码、音符输出和声音播放的完整功能链路。

**关键词：** 柔性薄膜压力传感器；信号调理；FPGA；Verilog；LM386；手指钢琴

# 第一章 技术指标

## 1.1 系统功能要求

本课题的目标是实现一个可实际操作的手指钢琴。使用者按压柔性薄膜压力传感器时，传感器产生电阻变化；系统将这种连续的压力变化转换为稳定的数字状态，再按照不同的三位编码输出不同音高。整个系统必须完成以下功能：

1. 三只压力传感器能够分别产生独立的按压信号；
2. 模拟电路能够把传感器信号处理为适合FPGA输入的低/高电平；
3. 三路状态组合形成000～111八种状态，其中000～110对应七个音符，111对应静音；
4. FPGA能够根据输入实时输出对应频率的方波；
5. 方波经功放后能够驱动扬声器，使操作者听到清晰的音高变化；
6. 电位器能够调节扬声器音量，系统在不按任何传感器时不发声。

本设计强调“传感器—模拟整形—数字译码—声音输出”各环节的连贯性。模拟部分保证输入可靠，数字部分保证频率准确，功放部分保证声音可听，从而构成完整的电子乐器基础系统。

## 1.2 系统结构要求

系统由电源与时钟模块、三路传感器调理模块、FPGA控制模块、音频功放模块及扬声器模块组成。模拟调理部分使用±5 V电源，FPGA和LM386分别使用与其相匹配的供电；所有模块的GND必须连接为公共地。2 MHz晶振为FPGA提供基准时钟，P79接3.3 V电源/逻辑高电平相关端，不参与三路传感器编码。

三路完全相同的调理电路输出分别送至FPGA：传感器1接A=P76，传感器2接B=P77，传感器3接C=P78。FPGA的P90为audio_out，接至功放输入。该结构把容易受干扰的模拟采样和频率精确的数字分频分开处理，便于逐级调试。

## 1.3 技术指标

1. 传感器按下时，进入FPGA的电平应接近0 V；不按时应为约3 V高电平。
2. 三路输入分别为A、B、C，采用低电平有效的编码方式。
3. 时钟为2 MHz，FPGA根据半周期计数值产生音频方波。
4. 输出音符为C4、D4、E4、F4、G4、A4、B4，频率范围约261.62～493.88 Hz。
5. P90输出波形为约0～3.3 V方波；111状态下P90保持低电平。
6. 音频功放采用LM386，输出端经330 µF电解电容与扬声器耦合。
7. 频率误差要求小，实测结果以示波器读数为准。

## 1.4 设计条件

本设计使用面包板和XC3S50AN FPGA目标板实现。模拟运放TL084采用+5 V和−5 V双电源；LM386采用+5 V供电；FPGA的输入输出采用3.3 V LVCMOS电平。系统时钟为2 MHz。设计和烧录软件为Xilinx ISE，Verilog语言用于描述FPGA内部组合译码及计数分频逻辑。调试仪器包括万用表、示波器和FPGA下载器。

# 第二章 整体电路设计

## 2.1 整体方案设计

整体方案采用模块化设计。第一部分为三路柔性薄膜压力传感器及TL084信号调理电路；第二部分为FPGA译码和音频发生电路；第三部分为LM386功放与扬声器电路。传感器作为人机交互元件，FPGA作为音符产生核心，LM386作为功率输出级。模块之间只通过明确的电压信号和公共地连接，可降低相互干扰并便于定位故障。

**图2-1 系统总体框图（手绘）**

```text
FSR1 ─┐
FSR2 ─┼→ 三路TL084调理 → A/P76、B/P77、C/P78 → FPGA → P90 → LM386 → 扬声器
FSR3 ─┘                                         ↑
                                            2 MHz晶振/P124
P79：3.3 V电源/逻辑高电平相关端
```

传感器模块采用三路复制方式，避免不同通道之间因电路结构不一致而造成门限差异。FPGA只接收已经整形的数字电平，不承担模拟比较任务。功放置于数字输出之后，避免扬声器负载直接影响FPGA端口。

## 2.2 整体设计原理

柔性薄膜压力传感器的电阻随压力增加而减小。传感器和固定电阻构成分压网络后，按压和不按将得到明显不同的采样电压。该电压经过TL084的电压跟随器后获得较低输出阻抗，并与稳定的参考电压共同送入差分比较级。通过电位器设定合适门限，可以使轻按和松开状态被清晰区分。比较输出经R5和C1滤波后送入FPGA。

数字部分的基本思想是：先由组合逻辑根据{A,B,C}选择N值，再由计数器以2 MHz时钟计数。当计数达到N−1时，audio_out翻转一次，因此完整周期包含两个半周期，输出频率为f=2 MHz/(2N)。不同N值产生不同音符。111对应N=0，程序将audio_out强制为0，实现静音。

功放部分中，100 nF电容隔离P90的直流分量，100 kΩ电位器调节输入信号大小。LM386在默认增益下将音频信号放大，5脚输出经330 µF电解电容耦合至扬声器。这样既保护了扬声器，又避免直流分量持续流过扬声器线圈。

## 2.3 系统工作流程

系统上电后，FPGA完成配置并进入工作状态。若三路传感器均未按下，则A、B、C均为1，输入为111，扬声器静音。按下传感器后，对应通道输出变为0，FPGA根据新的输入组合立即选择相应分频值并从P90输出方波。方波经功放输出为声音。松开传感器后输入回到高电平，系统随之切换音符或回到静音状态。

# 第三章 单元电路设计

## 3.1 柔性薄膜压力传感器采样电路

### 3.1.1 设计思想

传感器本身输出的是阻值变化，不能直接送入FPGA。因此首先需要将阻值变化转换成电压变化，并使采样点电压满足低压工作要求。设计中采用电阻网络、传感器和电位器构成可调采样支路，使不同传感器之间的离散性可以通过调节电位器补偿。

### 3.1.2 设计原理及方案

单路电路中，R6为4.7 kΩ，R1为330 Ω，R10为1 MΩ电位器，R11为3.3 MΩ。传感器接入采样支路后，按压力度改变其阻值，从而改变送入运放输入端的电压。R10用于调整门限，使传感器在不按与按下时产生足够大的电压差。为了使传感器工作点对地电压保持较低，电阻网络经过实际调试确定；该方式可减少传感器端过高电压对柔性薄膜的影响。

**图3-1 单路传感器采样电路（附录正式图）**

三路传感器采用完全相同的元件参数和连接方法，只改变最终输出分别接P76、P77和P78。

## 3.2 电压跟随与参考电压电路

### 3.2.1 设计思想

传感器分压点阻抗较高，若直接送往差分比较级，后级输入阻抗和导线干扰可能影响采样结果。因此采用TL084电压跟随器实现阻抗变换；参考电压也采用跟随方式，使比较门限稳定。

### 3.2.2 设计原理及方案

单路电路中U1A构成采样信号跟随器，输出端反馈至反相输入端，输出电压近似等于同相输入端采样电压。R3为4.7 kΩ、R4为330 Ω构成参考支路，U3B作为参考电压跟随器。这样，一路输出代表传感器采样状态，另一路输出代表稳定门限。TL084为四运放芯片，三个通道实际使用3片TL084完成多路信号处理。

跟随器的作用不是放大电压，而是提高驱动能力、隔离前后级，使后续比较电路只判断电压差而不影响传感器采样网络。

## 3.3 差分比较、滤波与输出整形电路

### 3.3.1 设计思想

为了把连续变化的传感器电压转换成清晰的数字电平，采用差分放大/比较思想：将传感器跟随输出与参考跟随输出相比较。当按压使传感器电压跨越门限时，输出状态翻转。输出端增加RC网络，减少传感器按压瞬间的抖动。

### 3.3.2 设计原理及方案

U2D为比较与差分输出单元。R7、R8均为2 kΩ，R2、R9均为15 kΩ，R12、R13均为3 kΩ，构成比例匹配的电阻网络，使传感器信号与参考信号的差异在输出端得到明显反映。输出后串联R5=4.7 kΩ，并由C1=100 nF对地滤波。RC网络对快速尖峰具有抑制作用，使FPGA输入不会因接触抖动频繁翻转。

调试时以“不按输出约3 V、按下输出约0 V”为目标，逐路调节R10，直到两种状态均能被稳定识别。该单路电路复制三套构成完整模拟前端。

## 3.4 FPGA编码、分频与RTL设计

### 3.4.1 设计思想

FPGA部分采用硬件描述语言实现，避免使用软件延时。输入编码由组合逻辑立即译码，音频频率由时钟计数器产生。采用2 MHz基准时钟能够使七个音符的分频整数较小，利于实现和测试。

### 3.4.2 设计原理及方案

Verilog程序中，`case({A,B,C})`决定`div_num`。000选择2025，对应B4；110选择3822，对应C4；111选择0，并令audio_out为0。计数器每计数到`div_num-1`时翻转audio_out，方波周期由两个相同半周期构成。该逻辑结构清晰、资源占用少，RTL顶层图应画出clk_2m、A、B、C、译码模块、分频模块和audio_out。

UCF约束将clk_2m固定到P124，A、B、C固定到P76、P77、P78，audio_out固定到P90。P79接3.3 V电源/逻辑高电平相关端，不作为Verilog编码端口。

## 3.5 LM386音频功放与扬声器电路

### 3.5.1 设计思想

FPGA P90只能提供逻辑信号，不能直接为扬声器提供足够的电流，因此设置独立功放级。LM386外接元件少，适合本设计的单声道低功率音频驱动；电位器使声音大小可调，输出耦合电容保护扬声器。

### 3.5.2 设计原理及方案

FPGA输出端P90的信号为0～3.3 V的数字方波。该信号的电压幅度可以被LM386识别，但不能直接接到扬声器，原因是FPGA端口只能提供较小电流，扬声器却需要一定的驱动电流才能发出足够响亮的声音。因此，P90和扬声器之间必须设置隔直、音量调节、功率放大和输出耦合四个环节。

第一步为输入隔直。P90先串联100 nF电容，电容的作用是隔离FPGA端的直流分量，只把随时间变化的方波成分送入后级。这样可以防止电位器和LM386输入端长期带有不必要的直流偏置。100 nF电容后的节点接100 kΩ电位器的一个外脚，电位器另一个外脚接GND，中间脚作为可变输出送至LM386的3脚。转动电位器时，中间脚电压随分压比例改变，从而实现音量由小到大的连续调节。实际调试时，应先将电位器调至最小音量，待电源和P90方波均确认正常后再缓慢调大，可避免刚上电时音量过大或误接线造成扬声器持续响声。

LM386的2脚为反相输入端，本设计直接接GND；3脚为同相输入端，接电位器中间脚；4脚接GND；6脚接+5 V。为了让LM386在发声瞬间仍具有稳定供电，在6脚与GND之间并联100 nF去耦电容。该电容应尽量靠近芯片6脚和4脚布置，用于旁路电源线上可能出现的高频干扰，避免功放将电源波动放大成杂音。1脚、7脚和8脚在本设计中均不连接，LM386使用默认增益，既能满足课堂验收所需的音量，也使外接元件数量保持较少。

LM386的5脚为功放输出端。5脚不能直接接扬声器，而要先接330 µF电解电容的正极，电解电容的负极再接扬声器一端，扬声器另一端接GND。这样连接的原因是5脚输出带有直流工作电位，330 µF电容只允许交流音频信号通过，阻止直流电流长期流过扬声器线圈。电解电容的极性必须正确：正极接LM386的5脚，负极接扬声器侧；若反接会使电容工作状态异常。图3-5所示为P90之后的功放和扬声器连接关系。

**图3-5 P90至LM386扬声器功放电路（附录正式图）**

功放部分的接线检查可按“供电—输入—输出”的顺序进行。首先断电核对LM386缺口方向以及1～8脚位置；然后用万用表确认6脚对GND为+5 V、2脚和4脚确实为GND；再确认P90经过100 nF电容后进入电位器，电位器中间脚只接3脚；最后检查330 µF电容正极在5脚侧、扬声器另一端回到公共地。模拟调理电路、FPGA板和LM386虽然分别使用不同电源，但三者的地必须相连。公共地提供了P90方波和功放输入所共同参考的0 V基准，是整个系统能够正常发声的必要条件。

## 3.6 三路复制和系统互连说明（整体电路）

### 3.6.1 三路复制原则

本设计不是只使用一路传感器，而是将单路“传感器采样—电压跟随—参考跟随—差分比较—RC滤波”电路完整复制三次。复制三路而不是把三只传感器直接并联，有两个原因。第一，三个传感器的阻值范围、灵敏度和按压面积可能存在差异，独立支路可以分别调节，使每一路都获得适合FPGA识别的高低电平。第二，若多只传感器共用一个比较支路，某一只传感器的状态可能改变其他通道的分压条件，导致编码不稳定。采用三套独立调理电路后，A、B、C三路具有相同的电路结构和相互独立的输出节点，便于逐路测量与故障定位。

三路调理单元在功能上完全相同，但元件在面包板上的位置和导线长度可以不同。实际搭建时，每完成一路，应先单独检查该路的传感器采样点、跟随器输出、参考输出和最终输出，确认“不按为高、按下为低”后再搭建下一路。这样能够把故障范围限制在一个通道内。三路全部合格后，再把输出端分别接到FPGA板的P76、P77和P78。本报告中的正式总电路图采用“单路完整画出并复制三份”的方式表达，既反映真实装配结构，也使三路信号的去向清晰可查。

### 3.6.2 模拟部分与FPGA的接口关系

传感器1调理输出定义为A，接P76；传感器2调理输出定义为B，接P77；传感器3调理输出定义为C，接P78。三路接口均采用低电平有效方式，即按压传感器时对应输入趋近0 V，松开时对应输入接近3 V。FPGA程序使用`case({A,B,C})`读取这三个状态，因此A、B、C的排列顺序不能在硬件接线和程序中任意调换。例如，若实际把传感器2接到了P78而程序仍把P77当作B，则组合编码会发生变化，按下同一只传感器时得到的音符也会改变。

在连接FPGA之前，必须先以公共地为参考测量三路输出。P76、P77、P78的输入电压应处于FPGA能够可靠区分的范围内。本设计实测不按时分别为2.79 V、2.95 V和3.00 V；按下时分别为0.201 V、47.5 mV和−28.7 mV。由此可见，三路高、低电平之间具有明显裕量。P78测得的−28.7 mV属于毫伏级零点偏置，在数字判断中可视作0 V。信号线在面包板上应尽量短，并避免与扬声器输出线长距离平行，以降低功放和导线对高阻模拟节点的影响。

FPGA的P124接2 MHz晶振输出，为整个音频发生逻辑提供统一时间基准；P79按开发板实际接口接3.3 V相关端，不属于Verilog顶层输入，也不参与三位编码；P90为`audio_out`，输出0～3.3 V方波。P90只接功放输入网络，不直接接扬声器。这样的接口划分使模拟前端、数字处理和功率输出三级职责明确：模拟前端负责把压力变成逻辑状态，FPGA负责把逻辑状态变成频率，LM386负责把频率信号变成可听声音。

### 3.6.3 电源、地线与布线要求

TL084调理电路使用+5 V和−5 V双电源，LM386使用+5 V单电源，FPGA输入输出则采用3.3 V LVCMOS逻辑电平。不同电源电压的正端不能混接，但它们的GND必须连接为公共地。公共地不仅是电源回流路径，也是所有电压测量和逻辑判断的参考点。若模拟地与FPGA地没有连接，P76～P78的电压即使在模拟部分测量正常，FPGA仍可能把输入识别为不确定状态；若LM386地没有与P90参考地相连，则功放输入没有正确的信号回路，容易出现无声或杂声。

实际布线时，建议将电源线、信号线和扬声器线分开安排。±5 V电源线沿面包板电源区分配；P76、P77、P78信号线采用短导线引到FPGA板；P90到功放的线不宜从传感器高阻采样点附近穿过；330 µF电解电容和扬声器接线应靠近LM386输出侧。每次插拔导线前先关闭电源，修改完一处后再通电测量，可以避免短路或误把±5 V送入FPGA的3.3 V I/O端。

# 第四章 电路调试与测试

## 4.1 传感器采样与输入电平测试

### 4.1.1 测试目的和方法

传感器调理部分是整个系统的输入基础。若该部分输出不稳定，后续FPGA会把压力状态误判为错误编码，因此在连接数字部分前必须先完成直流电压测试。测试使用万用表直流电压档，黑表笔始终接公共GND，红表笔依次接P76、P77、P78的实际输入节点。每一路分别记录传感器完全松开和稳定按下时的电压。测试时不把黑表笔接到−5 V、LM386输出端或任意浮空节点，以免引入错误参考。

调试顺序为：先给模拟调理部分供电，确认TL084的+5 V、−5 V供电正确；再测传感器分压点，确认该点满足低压要求；然后测比较滤波后的输出；最后将该输出接入相应FPGA管脚并复测。若不按与按下两个数值的差异不够明显，应在断电后检查R10调节位置、传感器接触和参考电压支路，而不能直接把不确定电压送入FPGA。

### 4.1.2 实测结果与分析

| 输入端 | 不按/V | 按下/V | 结论 |
|---|---:|---:|---|
| P76（A） | 2.79 | 0.201 | 高/低电平清晰 |
| P77（B） | 2.95 | 0.0475 | 高/低电平清晰 |
| P78（C） | 3.00 | −0.0287 | 高/低电平清晰 |

由测试可知，三路不按电压均接近3 V，按下电压均接近0 V。以P76为例，高、低状态相差约2.59 V；P77相差约2.90 V；P78相差约3.03 V。这样的状态差异足以使FPGA可靠地区分逻辑1和逻辑0。P78的−28.7 mV远小于1 V，不会影响低电平判断，可按0 V处理。上述数据验证了三路模拟调理电路具有一致的状态转换方向，也证明R5、C1滤波后输出可作为FPGA编码输入。

从三个通道的结果还可以看出，不按电压并不要求严格相同。例如P76为2.79 V、P78为3.00 V，二者均处于高电平区域；按下电压也不要求恰好等于0.000 V，只要保持在低电平区域且状态稳定即可。实际元件有阻值误差，柔性传感器本身也具有离散性，因此本设计采用可调门限和逐路调试方式来保证最终逻辑效果，而不是强行追求每一路完全相同的模拟数值。

## 4.2 时钟和P90方波测试

### 4.2.1 时钟检查

FPGA输出频率完全由2 MHz基准时钟决定，因此先检查时钟再检查音频输出。示波器探头尖端接P124，地夹接FPGA公共GND，设置DC耦合和×10探头。若示波器可读出约2 MHz的周期性波形，说明晶振输出、P124连接和FPGA时钟输入基本正常。测量高频时可把时基调到约200 ns/div至500 ns/div，使若干个时钟周期显示在屏幕上；不要把探头地夹夹到−5 V或其他电源端。

### 4.2.2 P90波形检查

P90是程序`audio_out`的物理输出脚。测量时探头尖端接P90，地夹仍接公共GND，推荐使用DC耦合、×10探头、1 V/div，时基先设为1 ms/div，再根据音符频率调整。触发方式选择边沿触发，触发源选当前通道，触发沿选上升沿，触发电平设在约1.5 V。这样可使方波在示波器上稳定显示。若幅度显示过小，先检查探头是否设置为×10以及示波器通道衰减比是否与探头一致；若波形滚动，则调整触发电平或时基。

输入为111时，程序将`div_num`置0，并强制`audio_out`为0，因此示波器应显示接近0 V的直线；输入为000～110时，计数器按相应半周期值翻转输出，示波器应显示稳定的0～3.3 V矩形波。方波的占空比接近50%，其频率随输入编码变化。P90首先必须在未接或低音量功放状态下确认正确，再接入LM386，以避免把模拟功放故障和数字波形故障混在一起判断。

### 4.2.3 波形异常的定位方法

若P90始终为低电平，应先检查A、B、C是否全部为111，随后检查P124时钟和烧录是否成功；若P90始终为高电平或无规则电平，应检查P90管脚约束、公共地和示波器地夹位置；若P90有波形但频率明显不对，应核对`div_num`表、时钟频率以及晶振连线。若P90波形正常而扬声器无声，问题通常在100 nF耦合电容、电位器、LM386的6脚供电、330 µF电容极性或扬声器接线。以这种由前向后的顺序排查，可以减少重复拆线。

## 4.3 七种编码的频率测试与误差分析

### 4.3.1 频率计算依据

程序中每当计数器达到`div_num−1`时，`audio_out`翻转一次。因此一个完整方波周期包含两个相同的计数过程，输出频率为：

```text
f = 2 000 000 / (2 × div_num)
```

例如C4对应`div_num=3822`，理论输出频率约为2 000 000÷(2×3822)=261.64 Hz；B4对应`div_num=2025`，理论输出频率约为493.83 Hz。程序采用整数计数，实际值与音乐标准频率之间会有很小的量化差，但该差异远小于验收所需的分辨能力。

频率误差计算公式为：

```text
频率误差（%）＝|实测频率－标准频率|÷标准频率×100%
```

| 输入 | 音符 | 标准/Hz | 实测/Hz | 误差/% |
|---|---|---:|---:|---:|
| 000 | B4 | 493.88 | 493.8271 | 0.011 |
| 001 | A4 | 440.00 | 439.9472 | 0.012 |
| 010 | G4 | 391.99 | 392.0031 | 0.003 |
| 011 | F4 | 349.23 | 349.2839 | 0.015 |
| 100 | E4 | 329.63 | 329.5979 | 0.010 |
| 101 | D4 | 293.67 | 293.6857 | 0.005 |
| 110 | C4 | 261.62 | 261.6431 | 0.009 |
| 111 | 静音 | 0 | 0 | — |

实测最大误差为0.015%，各音符频率均与预期相符。说明计数值选择、2 MHz时钟和FPGA分频逻辑正确。七个频率由低到高依次为C4、D4、E4、F4、G4、A4、B4，频率顺序连续递增，听觉上表现为音高逐级升高。对于111静音状态，`div_num=0`，程序并不继续计数，而是直接将输出拉低，因此表中以“0”和“静音”表示，不进行百分比误差计算。

### 4.3.2 编码、音符与操作方式说明

本设计的三路传感器采用低有效编码，故不按时为111并保持静音，按下若干传感器后对应位变为0。验收时可通过按压组合或用导线模拟高低电平组合观察不同频率。为了记录结果，应按000、001、010、011、100、101、110、111的顺序依次施加输入，等示波器频率读数稳定后填写表4-2。这样既能验证七个音符，也能验证111状态是否真正关闭音频输出。

## 4.4 LM386及扬声器工作测试

### 4.4.1 测试步骤

调试功放时先将电位器调至最小，确认LM386 6脚对地为+5 V且芯片不发烫，再确认P90存在正确方波，最后接入功放并逐渐增大音量。测试顺序具体如下：

1. 断电检查LM386方向、2脚和4脚接地、6脚接+5 V、5脚接330 µF电容正极；
2. 上电后用万用表测6脚对地电压，确认约为+5 V；
3. 保持功放输入端暂不接或电位器最小，先在P90处确认方波；
4. 将P90经100 nF电容接入电位器和3脚，选取任一发声编码；
5. 缓慢旋转电位器，听取扬声器声音，并切换多个编码检查音高变化；
6. 切换到111，确认扬声器停止发声。

测试中，000状态可听到B4音；改变编码时音高相应改变；111状态无声；旋转电位器可改变音量。说明LM386、耦合电容及扬声器连接正确。

| 测试项目 | 结果 |
|---|---|
| 编码改变后音高改变 | 正常 |
| 111状态静音 | 正常 |
| 电位器音量调节 | 正常 |
| 扬声器持续发声 | 正常 |

### 4.4.2 功放工作现象分析

LM386的任务是提升驱动能力，而不是改变音符频率，所以只要P90频率正确，扬声器的音高应与示波器读数一致。电位器主要改变输入幅度，因此旋转电位器时声音大小变化而音高不变。若声音较小，优先检查电位器是否处于最小位置、6脚供电是否为+5 V以及扬声器是否连接到330 µF电容后；若出现明显的持续杂音，则检查公共地、去耦电容及P90到功放输入的导线走向。通过将数字输出波形和最终听觉效果分开验证，可以证明系统完成了从逻辑编码到可听声音的完整转换。

## 4.5 验收三基本指标对应关系

验收三要求给出FPGA输入端按下与不按下时的电压，并验证扬声器是否工作和信号频率是否正确。本设计将该要求分解为三个可直接展示的项目。第一，使用万用表测P76、P77、P78，显示三路均具有明确的高、低电平；第二，使用示波器测P90，显示输入状态改变后方波频率随之变化；第三，连接LM386和扬声器，听取不同编码对应的不同音高，并在111状态验证静音。三项结果互相对应：输入电压证明传感器状态已正确进入FPGA，P90频率证明程序译码和分频正确，扬声器声音证明后级功放连接正确。

验收展示时可按如下顺序操作：先展示三路传感器均不按时的输入电压；再按压某一路或改变组合，展示对应输入变低；随后把示波器探头接P90，切换编码观察方波频率；最后接入扬声器，播放几个由低到高的音符，并回到111展示静音。该流程从输入、处理到输出逐级呈现，使验收数据与系统功能一一对应。

## 4.6 调试安全与记录规范

面包板系统连线较多，调试过程中应采用断电改线、上电测量的基本原则。TL084使用±5 V电源，FPGA I/O只能接收3.3 V逻辑信号，二者的电源正端绝不能混接。每次上电前应先观察是否有裸露导线相碰，再用万用表确认电源轨之间没有明显短路。示波器地夹连接公共GND时，不应同时夹在多个不同参考点上；尤其不应夹到−5 V电源端，以免造成错误连接。

数据记录应注明测量位置、输入状态和单位。例如“P77，按下，47.5 mV”比只记录“47.5”更容易追溯。频率表中的标准值、实测值和误差应使用同一单位Hz。实物图、示波器图和ISE烧录成功截图作为附录材料保存，可使调试结论具有清晰的依据。通过规范记录，后续即使需要重新接线或复现实验，也能依据表格快速恢复各模块的工作状态。

# 第五章 设计总结

## 5.1 设计任务完成情况

本设计已完成基础指标。三只柔性传感器的状态能够经模拟电路稳定送入FPGA；FPGA能够依据三位编码产生七个音符并实现静音；P90方波频率测试符合预期；LM386功放能够驱动扬声器。系统实际完成了“压力动作—模拟电平—数字编码—音频方波—扬声器声音”的完整闭环，而不是只完成单一的软件仿真或单一的模拟电路测试。

从输入端看，P76、P77、P78在按下和不按时均获得清晰的高低状态；从数字端看，2 MHz时钟分频得到的C4至B4频率实测误差最大为0.015%；从输出端看，P90经LM386后可以驱动扬声器，电位器能够调节音量，111状态可以静音。上述结果说明三路传感器调理、FPGA程序、管脚约束、功放和扬声器各部分已正确互连。本设计没有进行扩展指标，报告内容围绕已完成的基础功能和实际测得数据展开。

## 5.2 调试经验和问题可改进方向

本设计最重要的调试经验是采用“先模拟、后数字、再功放”的分级顺序，而不是把所有模块一次接好后再盲目寻找故障。第一阶段只检查每一路传感器调理输出，目标是使不按状态稳定为高电平、按下状态稳定为低电平；第二阶段将三路信号接入FPGA，检查P124时钟、UCF管脚约束和P90方波；第三阶段才接入LM386和扬声器。每一阶段都有明确的测量点和判断标准，因此故障出现时可以快速定位在传感器支路、FPGA部分或功放部分。

在模拟调试中，电位器的作用非常关键。不同FSR传感器的阻值变化范围并不完全相同，若三个通道使用完全固定的门限，某一路可能轻按时不翻转或松开后无法回到高电平。通过逐路调节R10，并以最终P76、P77、P78的高低电平为准，可将元件离散性转换为可调参数。调节时不应只看传感器采样点，而应同时观察最终比较滤波输出，因为FPGA实际接收的是该输出节点。

在数字部分，程序端口、UCF约束和实际导线必须一一对应。最终顶层端口为`clk_2m`、A、B、C和`audio_out`，因此UCF只约束P124、P76、P77、P78和P90。若使用了旧的仿真顶层或旧UCF，其中的`rst_n`、`sensor_in`、LED等信号与当前实际烧录端口不一致，就会使ISE综合或管脚设置出现混乱。实际烧录前检查顶层模块名称是否为`finger_piano`、器件是否为XC3S50AN-5TQG144、P90是否设置为输出，是保证下载成功的重要步骤。

在功放调试中，先用示波器确认P90存在正确方波，再接扬声器是有效的方法。若没有先确认P90，扬声器无声时无法判断问题来自FPGA还是LM386。功放的常见检查点是6脚+5 V、2脚和4脚GND、3脚输入、5脚输出、330 µF电容极性以及公共地。电位器调至最小后再上电，可以使首次测试更安全。示波器地夹和功放地均接公共GND，能够避免因参考点不一致而出现的误判。

本系统后续可在不改变基础结构的前提下继续完善：第一，可将三路门限调节改为更集中、更便于标定的形式，使外观更整洁；第二，可在FPGA内部加入更严格的数字去抖判断，使传感器按压边沿更加平稳；第三，可增加LED显示当前三位输入或当前音符，方便演示和排错；第四，可对P90方波进行更丰富的音色处理，或采用更高质量的音频输出级；第五，可增加更多传感器通道和更高八度音阶。上述方向属于功能扩展，不影响本设计已经实现和验证的基础指标。

## 5.3 心得体会

本次课程设计使我把模拟电路、数字电路和实际装配调试联系起来。开始时，压力传感器在我看来只是一个会改变阻值的元件；经过本次设计，我认识到阻值变化并不能直接成为数字系统可用的信息，必须经过分压、跟随、参考、差分比较和滤波，才能形成稳定的0/1状态。三路输入电压的实际测量也说明，电路设计不能只停留在理论数值上，元件误差、传感器个体差异和面包板接线都会影响最终工作点，需要通过合理的调试方法使系统达到可靠状态。

FPGA部分让我进一步理解了硬件描述语言与实际物理信号之间的对应关系。程序中的`case({A,B,C})`看似只是八种组合判断，但它对应着三根实际导线上的高低电平；程序中的`div_num`看似只是若干个整数，却直接决定扬声器发出的音高。通过示波器观察P90的方波、读取频率并与标准频率比较，我理解了“时钟—计数—翻转—频率”之间的定量关系，也体会到UCF约束文件对程序和实际管脚连接的重要性。

功放和扬声器部分使我认识到数字输出并不等于最终可用的声音输出。P90方波正确只是数字部分完成，只有经过耦合、电位器、LM386和扬声器后，系统才真正具有乐器的交互效果。调试过程中按照电源、输入、输出逐项检查，能把复杂系统拆分为可验证的小问题。这种分模块、逐级测量、记录数据的方法不仅适用于本课题，也可用于以后更复杂的电子系统设计。

总体来看，本次课程设计完成了从原理分析、参数选择、仿真验证、面包板装配、ISE综合烧录到示波器和扬声器测试的完整过程。我提高了使用万用表、示波器、ISE软件和面包板进行系统调试的能力，也更加重视公共地、供电极性、管脚约束和测试记录等工程细节。手指钢琴虽然结构紧凑，但它把传感器、模拟电子技术、数字逻辑和音频驱动结合在同一系统中，具有很强的综合实践意义。

## 附录D-1 Verilog源程序（finger_piano.v）

```verilog
`timescale 1ns / 1ps

module finger_piano (
    input  wire clk_2m,
    input  wire A,
    input  wire B,
    input  wire C,
    output reg  audio_out
);

    reg [11:0] count;
    reg [11:0] div_num;
    reg [15:0] por_count;
    reg        rst_n;

    initial begin
        count     = 12'd0;
        div_num   = 12'd0;
        audio_out = 1'b0;
        por_count = 16'd0;
        rst_n     = 1'b0;
    end

    // 上电自动复位约10 ms：2 MHz×10 ms＝20 000。
    always @(posedge clk_2m) begin
        if (!rst_n) begin
            if (por_count == 16'd19999)
                rst_n <= 1'b1;
            else
                por_count <= por_count + 1'b1;
        end
    end

    // 传感器按下为0；三路均不按时为111，系统静音。
    always @(*) begin
        case ({A, B, C})
            3'b111: div_num = 12'd0;
            3'b110: div_num = 12'd3822; // C4，261.62 Hz
            3'b101: div_num = 12'd3405; // D4，293.67 Hz
            3'b100: div_num = 12'd3034; // E4，329.63 Hz
            3'b011: div_num = 12'd2863; // F4，349.23 Hz
            3'b010: div_num = 12'd2551; // G4，391.99 Hz
            3'b001: div_num = 12'd2273; // A4，440.00 Hz
            3'b000: div_num = 12'd2025; // B4，493.88 Hz
            default: div_num = 12'd0;
        endcase
    end

    // 计满一个半周期后翻转一次，输出对应频率方波。
    always @(posedge clk_2m) begin
        if (!rst_n) begin
            count     <= 12'd0;
            audio_out <= 1'b0;
        end else if (div_num == 12'd0) begin
            count     <= 12'd0;
            audio_out <= 1'b0;
        end else if (count >= div_num - 1'b1) begin
            count     <= 12'd0;
            audio_out <= ~audio_out;
        end else begin
            count <= count + 1'b1;
        end
    end
endmodule
```
