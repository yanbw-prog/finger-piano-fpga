# ISE仿真与电路图符号说明

## 1. ISE能仿真什么

ISE只仿真FPGA内部的数字逻辑，即：

三路传感器0/1输入 → 同步 → 消抖 → 3位编码 → 七音分频 → audio_out方波

ISE中使用的文件：

- `Verilog源码/finger_piano.v`：设计文件。
- `Verilog源码/tb_finger_piano.v`：仿真激励文件。

ISE不能直接仿真以下部分：

- FSR压力传感器的阻值变化。
- TL084运算放大器。
- RC低通滤波器。
- LM386音频功率放大器。
- 喇叭的声音输出。

这些部分要用Multisim/Proteus仿真，或在面包板上用万用表和示波器测试。

## 2. ISE仿真操作顺序

1. 新建ISE工程，器件选择XC3S50AN对应的实际封装和速度等级。
2. 添加`finger_piano.v`为Design Source。
3. 添加`tb_finger_piano.v`为Simulation Source。
4. 在Simulation视图中选中`tb_finger_piano`。
5. 运行Simulate Behavioral Model。
6. 在波形窗口观察`sensor_in[2:0]`、`note_code[2:0]`和`audio_out`。
7. 检查001～111时`note_code`是否相同，`audio_out`是否输出不同频率的方波；000时应为0。

UCF约束文件不是行为仿真的必需文件，但下载到实际FPGA板前必须填入正确管脚。

## 3. 总电路图中的符号

| 符号 | 含义 | 是否表示电流方向 |
|---|---|---|
| 指向FSR的斜箭头 | 手指对压力传感器施加外力 | 否 |
| 指向电位器的斜箭头 | 电位器的滑动端，表示阻值可调 | 否 |
| 向上的箭头和`+5V` | 该节点连接+5 V电源 | 否 |
| 三条逐渐变短的横线 | GND，即0 V公共地 | 否 |
| 线路交点上的实心圆点 | 这些导线在电气上相连 | 否 |
| 运放三角形的`+` | 同相输入 | 否 |
| 运放三角形的`−` | 反相输入 | 否 |
| 电解电容旁的`+`、`−` | 元件极性，实物不能接反 | 否 |

## 4. 总图的阅读方向

总图不是按电流箭头阅读，而是按信号流向从左到右阅读：

FSR1～FSR3 → 三路分压 → TL084三路放大 → 三路RC滤波 → FPGA编码/分频 → LM386 → 喇叭

三条模拟通道的电路结构完全相同，只是分别连到`sensor_in[0]`、`sensor_in[1]`和`sensor_in[2]`。
